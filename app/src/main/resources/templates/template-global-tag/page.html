@TemplateGlobal Variable in User Tag

The \{#orderSummary} user tag uses date_pattern which is provided by a @TemplateGlobal class, not passed as a parameter.

It works at runtime because @TemplateGlobal variables are available in all templates, but IntelliJ reports "Missing required parameter(s) `date_pattern` of `orderSummary` user tag" (MissingRequiredParameter).
